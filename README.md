---

### 🎨 Core Sections Included

The website features a cohesive, smooth-scrolling single-page flow that houses the following sections:
* **🏠 Home & Bio:** A welcoming introduction to my professional persona.
* **🎓 About Me & Education:** Insights into my academic journey at IJSE.
* **🚀 Experience & Projects:** Showcasing my engineering background and application repositories.
* **📝 Assignments & Activities:** Dedicated modules tracking academic tasks and extra-curricular involvements.
* **🏆 Achievements & Gallery:** Visual and textual validation of my milestones and events.
* **📬 Contact Info:** A dedicated space for recruiters and peers to reach out.

---

### 💻 Key Highlights & UI/UX Features

* **📱 Flawless Responsiveness:** Engineered from scratch with optimized CSS Media Queries to transition seamlessly across **Mobile, Tablet, Laptop, and Desktop** screen sizes.
* **✨ Dynamic Project Cards:** Integrated smooth opacity-shifting hover effects that subtly adjust card visibility, bringing creative project details sharply into focus upon interaction.
* **📈 Interactive Assignment Modules:** Implemented custom CSS Transform Scale properties that smoothly expand assignment cards for enhanced readability and modern user engagement.
* **🔄 Advanced Component States:** Handcrafted button interactions utilizing customized `:hover`, `:active`, and `:focus` states to ensure an intuitive user experience.

---

### 🛠️ Tech Stack & Concepts Applied

* **Structure:** HTML5 (Semantic and clean element layouts)
* **Styling:** CSS3 (Custom transitions, transformations, Flexbox, and Grid systems)
* **Interactions:** JavaScript (For dynamic behavior and structural adjustments)
* **Deployment:** Hosted live on Vercel with automated deployment pipelines.
